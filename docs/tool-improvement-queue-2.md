# Tool-improvement queue 2: ten measured attempts from the per-tool benchmark

Status: **measured ledger of the second loop.** Branch `exp/tool-loop2`, base
`0f23d26c` (`main`). The loop starts from `docs/tool-quality.md`, so it targets
the measured implementation gaps (leaf skip/RD, intra/key coefficient RD,
rate-aware BAWP) instead of flag sweeps.

Every attempt is one contained, default-off env-gated code patch (or, where
noted, a measurement of an existing gate). Nothing was enabled in a preset, no
default changed, no pin changed, no new syntax was added. External encoders and
decoders are black-box binaries only; no third-party source was read.

K is `tools/kpi.py` interpolated linearly in rate to 100.000 kbps across the
candidate's own bracket, scored by `tools/oracle.py` with the AVM decoder.
Natural content is `testdata/nasa_480x240_30fps_60f.y4m` (60 frames, 30 fps,
8-bit 4:2:0). Probe content is generated by `tools/tool_probes.py` (same
geometry and frame count, closed-form textures, fixed seed).

## 1. Attempt 1 — future-error skip surcharge (kept)

**Why.** `docs/tool-quality.md` §4.1: nightly finds the exact ground-truth MV
on 78-100% of fractional-motion leaves but skips 76-91% of them, and the P
chain loses 2.3-5.8 dB against its own key. The leaf RD prices a skip with this
frame's prediction SSE only; the skipped error is then installed in the
reference and copied forward through subpel MC. The probe control that
disables `--video-leaf-rd` gains +4.1 K on `me_half`.

**Pinned first control (required before coding).** Nightly minus
`--video-leaf-rd` (the flag set spelled out, since `--nightly` forces it on) at
QP112/116/120: 26,757 / 25,029 / 23,638 B, matched **84.494 K**. It wins on
natural 240p as well as on the probe (+2.35 K over the 82.149 baseline), so
the skip pricing, not the probe texture, is the lever.

**Patch.** `src/pipeline/video/video_skip_drift.h` (new) and the three
skip-vs-residual comparisons in `video_frame_decision.cpp` (historical, R09,
pipe/eff-perc). The skip arm pays

```
J_skip = D_pred * (1 + alpha * mv_factor) + lambda * R_skip
```

with `D_pred` the prediction SSE the skip freezes, `alpha` the horizon weight,
and `mv_factor` 1 for a zero-MV skip and `AV2ENC_SKIP_DRIFT_NZMV` otherwise.
Defaults: `AV2ENC_SKIP_DRIFT` off, `ALPHA=4.0`, `ZEROMV=0.0`, `NZMV=1.0`, so
setting only `AV2ENC_SKIP_DRIFT=1` is the measured arm and gate-off decisions
are byte-identical.

**Natural 240p** (nightly + `AV2ENC_SKIP_DRIFT=1`) QP104/108/110/112:
27,206 / 25,511 / 24,700 / 24,000 B, K 82.300 / 82.761 / 82.900 / 82.470,
matched **82.848 (+0.70)**. The bracket points are both above the baseline at
iso-rate (QP108 102.0 kbps vs base QP106 100.0: +0.61 K; QP110 98.8 kbps vs
base QP108 97.2: +1.30 K).

**Probe.** `me_half` QP150/152: 25,381 / 24,939 B (101.5 / 99.8 kbps), K 76.448
/ 76.050, matched **76.105** vs 71.615 baseline (**+4.49**). BA falls 14.36 →
5.70 and JOD rises 9.578 → 9.674: the skip→residual flip is the measured
mechanism, not a metric shift. This closes the probe gap the benchmark records
(the no-leaf-RD control is 75.67; eff-perc 75.76).

**Static gates.** `static_repeat` at QP132 is **byte-identical** (24,993 B,
MD5 `595974f6...`, 3,127 zero-MV skips, 445 residual leaves). `near_static` at
QP139 is byte-identical (22,578 B, MD5 `da71dbca...`). The zero-MV factor
default of 0 is what preserves these.

**Rejected arm (measured negative).** Charging the zero-MV skip too
(`AV2ENC_SKIP_DRIFT_ZEROMV=1`) is a bigger natural win (matched **84.403**,
+2.25 K; QP114/116/118 at 106.2/103.2/97.8 kbps, K 84.609/84.295/84.476) and a
slightly bigger probe win (76.201, +4.59), but it codes residual on exact
static content: `static_repeat` leaves flip to 1,701 skip / 1,808 residual and
the matched rate is 87.831 vs 88.837 (**-1.01 K**). The benchmark's own gate
(static/near-static must stay 100% zero-MV skip) rejects it. The zero-MV
surcharge needs a reference-deficit condition, which this loop did not ship.

## 2. Attempt 2 — intra/key coefficient trellis (negative, reverted)

**Patch.** New `AV2ENC_RDOQ_INTRA_TX` gate. The gated path runs the existing
`rdoq_quantize()` trellis on every intra luma TX candidate inside the search
(not as a post-winner refinement), initialises the §8.3 model with
`is_inter = false` and the frame `base_q_idx` CDF slice (§8.2.6 context
selection), prices the candidate with the unscaled exact model bits (the inter
path keeps its measured 0.4 calibration), and sets the trellis lambda to the TX
search's own lambda instead of the hand-tuned SSE scale the first loop used.
The key TX size/type/partition search therefore sees the trellis cost, which is
the benchmark fix `docs/tool-quality.md` §5.1 asks for.

**Key-only RD** (`detail_edges`, `--frames 1`, decoded PSNR-Y):

| QP | base B / dB | gate B / dB |
|---:|---|---|
| 124 | 29,441 / 42.119 | 27,933 / 41.641 |
| 132 | 25,851 / 40.368 | 24,592 / 40.082 |
| 139 | 23,039 / 38.881 | 22,001 / 38.701 |

At iso-rate the key gains **+0.26..+0.38 dB**, i.e. the mechanism is real but
two orders of magnitude short of the 8.4 dB AVM gap, and it buys that by
spending quantization accuracy differently, not by coding the same picture
better.

**Full probe** (`detail_edges`, 60 frames): gate QP136 24,940 B / 99.76 kbps /
K 84.027 vs baseline QP139 24,989 B / 99.96 kbps / K 84.122. PSNR is +0.42 dB
(39.32 vs 38.91) but BA is 2.06 vs 1.89, so **K is -0.095**: flat, not the
8.1-dB gap closure.

**Natural 240p**: gate QP100/102/104/106 = 24,364 / 23,692 / 23,367 / 22,598 B,
K 79.796 / 80.161 / 80.306 / 80.025. At iso-rate (97.5 vs 97.2 kbps) this is
**-1.81 K** against the baseline, and the gate never reaches 100 kbps at these
QPs. This repeats the first loop's shape (`AV2ENC_RDOQ_INTRA` −0.76 K) with a
different, more exact implementation: the key RD curve improves but the P
chain's reference quality falls at a fixed QP, and the saved bytes cannot be
spent at the operating point. **Negative, reverted.**
## 3. Attempt 3 — rate-aware BAWP acceptance (negative, reverted)

**Patch.** `AV2ENC_BAWP_RD`. The candidate stage keeps a copy of the plain
prediction when the fitted BAWP is applied; after both luma plans exist the
leaf compares `plain + residual` against `BAWP + residual` with the leaf
lambda. The coefficient plans are the exact TX-search plans (same RDOQ/TX
model as the emitted stream), chroma is identical, and both forms code the
`use_bawp` symbol, so only its value probability is charged (1 bit default).
The rejected form restores the original candidate (including a GLOBALMV
carrier swap).

**Fade.** The gate rejects BAWP on 8 of 40 BAWP leaves in a 3-frame trace.
QP117/119/121 with the gate: 25,625 / 24,889 / 24,028 B, K 83.205 / 82.817 /
82.955; baseline 25,708 / 24,994 / 24,247 B, K 83.329 / 82.695 / 82.483.
Matched rate: **82.876 vs 82.701 (+0.175)**, but the QP117 point is -0.09 at
its own iso-rate and the other two are +0.18/+0.51.

**Natural 240p.** 26,072 / 25,007 / 24,222 B, K 82.081 / 81.824 / 81.582;
matched **81.821 vs 82.149 (−0.328)**. The fade gain does not transfer, so the
change fails the sign-consistency rule. The no-BAWP CLI ablation's +1.7 K is
mostly candidate-ranking and skip-decision motion, not the residual plan of
the BAWP winner; this per-leaf comparison only sees the latter.
**Negative, reverted.**

## 4. Attempt 4 — exact TX-plan rate in the leaf decisions (kept)

**Why.** The TX search already prices each candidate plan with the §8.3 model
under `--video-rdoq`, but `decision_coeff_bits()` still charges the historical
heuristic (`8 + 2.5*nz + 0.5*eob` per part) to the skip/residual and
intra/inter decisions. The heuristic over-prices sparse plans, so a leaf whose
exact coded residual is cheap can still be skipped. This is the residual /
entropy allocation layer the benchmark gap points at, not a lambda sweep.

**Patch.** `AV2ENC_DECISION_EXACT_RATE` (default off) makes
`decision_coeff_bits()` return the searched plan's own `rate_bits` (the TX
search's measured §8.3 cost) instead of the heuristic. Non-searched plans
(chroma, the scalar path) keep the historical estimate. Gate off is
byte-identical (nightly QP110 pin `1b99127a...`).

**Natural 240p.** QP106/108/110/112: 26,828 / 25,687 / 25,000 / 24,073 B, K
83.139 / 81.661 / **83.112** / 82.833. QP110 is exactly 100.000 kbps / 25,000 B
so the matched point needs no interpolation: **83.112 vs 82.149 (+0.96)**. The
QP108 point is a local BA spike (3.89); the QP112 point is +1.4 against the
baseline at its iso-rate.

**Probe.** `me_half` QP148/149/150: 25,170 / 24,872 / 24,211 B, K 72.945 /
73.062 / 72.964; matched **73.012 vs 71.615 (+1.40)**. The gain is smaller than
the skip-drift patch (76.105) because it prices the residual better but does
not add the future term; it is a different mechanism and can compose.

**Static gates.** `static_repeat` QP132 MD5 `595974f6...` and `near_static`
QP139 MD5 `da71dbca...` are byte-identical to the baseline.

## 7. Attempt 7 — fade-bias gate for the zero-MV skip (kept)

**Why.** Attempt 1's full-charge arm was the biggest natural win (+2.25 K) but
coded residual on exact static content (static_repeat −1.01 K). The remaining
question is which zero-MV skips carry a real future error. On a fade the answer
is the signed DC bias: a zero-MV skip freezes the illumination ramp in the
reference. Exact static content and sensor noise have a near-zero leaf mean
error, so they can stay skip-only.

**Patch.** `AV2ENC_SKIP_DRIFT_FADE` (with `AV2ENC_SKIP_DRIFT=1`) computes the
leaf's mean signed prediction error once per zero-MV skip and, when it exceeds
`AV2ENC_SKIP_DRIFT_FADE_T` (default 1.0 LSB, i.e. a real DC bias), charges the
same future-error surcharge the non-zero-MV path already pays. It does not use
the BAWP fit alpha: on the fade probe that fit is pinned near 256 (242-265 over
2,793 candidates), so alpha is not fade evidence in this implementation.

**Fade.** QP119/121/123: 25,436 / 24,552 / 23,934 B, K 84.219 / 84.035 /
83.257; baseline 24,994 / 24,247 B, K 82.695 / 82.483. Matched **84.128 vs
82.701 (+1.43)**; BA 2.14 vs 2.40 and JOD 9.75 vs 9.67. This recovers most of
the no-BAWP ablation's +1.7 K by coding the fade residual instead of freezing
it.

**Natural 240p.** QP110/112/114/116: 25,880 / 24,983 / 24,288 / 23,430 B,
K 83.588 / 83.471 / 83.418 / 83.040; matched **83.473 vs 82.149 (+1.32)**. The
previous nz-only gate was +0.70.

**Probe and static gates.** `me_half` matched **76.105** — identical to attempt
1, because the periodic probe's zero-MV leaves have no DC bias. `static_repeat`
`595974f6...` and `near_static` `da71dbca...` remain byte-identical.

## 9. Attempt 9 — distortion-guarded intra trellis (negative, reverted)

**Patch.** `AV2ENC_RDOQ_INTRA_GUARD`: the attempt-2 intra trellis re-run as a
winner-only refinement, accepting a refined leaf only when its reconstruction
SSE does not increase (the key is the P-chain predictor, so a rate saving at
equal distortion would be the only safe form). Candidate pricing used the exact
§8.3 model, as in attempt 2.

**Result.** Key-only `detail_edges`: QP132 24,543 B / 40.111 dB vs 25,851 /
40.368; QP139 22,073 B / 38.736 vs 23,039 / 38.881. The SSE guard does not
preserve picture quality because the candidate stage's exact pricing changes
which partitions/types win (the guard only gates the final refinement). The
natural 240p streams are byte-identical to attempt 2 (QP104/106 23,367 /
22,598 B), so the matched-rate result is the same **−1.8 K**. **Negative,
reverted.**
